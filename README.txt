SAF TRADE UKRAINE — FINAL PRODUCTION THEME v4.2
==============================================

Project
-------
LLC SAF TRADE UKRAINE / ТОВ «САФ ТРЕЙД УКРАЇНА»
Public website language: Ukrainian.
Approved design direction: premium, modern, dark-green B2B flower wholesale.

FINAL v4.2 includes
-------------------
- Approved v4 homepage and branding direction preserved.
- Responsive desktop/tablet/mobile layout.
- Main navigation: Home, Catalogue, About, Wholesale, Delivery, Contacts.
- Flower custom post type and editable flower categories.
- Reusable individual flower/product pages with B2B specifications.
- Catalogue search and category filtering.
- Quick quote modal and contact/quote forms.
- AJAX validation, honeypot anti-spam and consent checkbox.
- Quote requests saved under WordPress Admin → Оптові запити.

- About, wholesale, delivery/logistics and contact pages seeded when missing.
- Automatic menu/page/category/product repair after theme update.
- 404/rewrite repair for product and category permalinks.
- Admin-toolbar/sticky-header overlap fix.
- Local bundled wholesale-market image for the critical wholesale section.
- Global image error fallback so a failed external image cannot leave a broken blank block.
- SEO description, Open Graph basics and Organization schema.
- Gutenberg/editor support and Customizer company/contact settings.

Installation / update
---------------------
1. Keep a backup of the current WordPress site.
2. Appearance → Themes → Install new theme → Upload theme.
3. Upload the final ZIP and choose Replace current with uploaded when prompted.
4. Keep/activate “SAF Trade Ukraine”.
5. Open WordPress Dashboard once after updating; the theme repairs required pages/menu/rewrite rules when needed.
6. Hard refresh the public site (Ctrl+F5) if WordPress/browser cache still shows old assets.

Client data that must stay real
-------------------------------
The theme intentionally does not invent the client’s phone number, business e-mail, street address, social links, exact prices, stock or delivery guarantees. Enter verified values in:
Appearance → Customize → SAF Trade — бренд і контакти.
