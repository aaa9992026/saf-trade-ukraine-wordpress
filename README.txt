# SAF Trade Ukraine — WordPress Theme

Custom WordPress website for **ТОВ «САФ ТРЕЙД УКРАЇНА» / LLC SAF TRADE UKRAINE**, designed for B2B flower wholesale operations.

## Features

- Custom responsive WordPress theme
- Premium flower catalogue
- Reusable flower/product templates
- Category filtering and search
- B2B inquiry/request form
- Inquiry saving in WordPress admin
- SMTP email notifications
- Responsive desktop, tablet, and mobile layouts
- Ukrainian-language content
- Custom About, Wholesale, Delivery, FAQ, and sourcing pages
- SEO-friendly structure
- Clean premium brand styling

## Installation

1. Download or clone the repository.
2. Compress the theme folder into a ZIP file if needed.
3. In WordPress go to:
   `Appearance → Themes → Add New → Upload Theme`
4. Upload and activate the theme.
5. Save WordPress permalinks once after activation.

## Email Configuration

The website supports SMTP email notifications through WP Mail SMTP.

SMTP credentials are **not included in this repository** and must be configured separately in WordPress.

## Security

This repository does not include:
- WordPress passwords
- SMTP passwords
- hosting credentials
- database credentials
- `wp-config.php`
- private environment secrets
